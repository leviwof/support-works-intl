# support-works-intl

Fullstack website for **Support Works International, Inc.** built with Next.js (App Router), Tailwind CSS, TypeScript, and Space Grotesk.

- **URL:** [https://supportworksinternational.com/](https://supportworksinternational.com/)
- **Features:**
  - 57 individual and bundled technology, website, and digital services
  - Real-time catalog search and interactive spotlight slider
  - Dedicated multi-page routing (`/`, `/about`, `/services`, `/approach`, `/contact`)
  - Full-fidelity legal and policy documentation (Privacy, Terms, Payment, Service Delivery)
  - Seamless contact and consultation inquiry form
